# 02_Code_Source - Edge / Fog / Cloud / IA

Water-network **leak detection and localization** on the Hanoi benchmark:
ESP32 Edge nodes (TinyML detector) -> Fog gateway (MQTT + localization) ->
Cloud (training, versioning, drift). See `01_Rapport/report.pdf` for the full
design and the placement recommendation.

## Repository layout

```
02_Code_Source/
  edge/    ESP32 firmware (edge_node.ino, FreeRTOS), model.h (TinyML),
           test_data.h (replay set), sensor_stream.h, emulated_node.py (paho)
  fog/     Mosquitto config (auth + ACL), setup_auth.sh, fog/service.py,
           dashboard/ (Streamlit, 6 pages), Dockerfiles
  cloud/   cloud_api.py (FastAPI REST), train.py (retraining + registry)
  ia/      data loading, training (edge detector, fog localizer), drift.py,
           experiments (static + live), consistency check, model exports
  requirements.txt  docker-compose.yml  .env.example
```

Generated artifacts (not in git / not in the ZIP):
`04_Donnees/generated/` (full dataset), `results/` (measurements), `ia/models/`
(trained fog models).

## Reproduce from a clean install (Linux, Python 3.12)

```bash
# 1. environment
python3 -m venv .venv && . .venv/bin/activate
pip install -r 02_Code_Source/requirements.txt

# 2. dataset (~3 min, SEED=42, deterministic)
python 04_Donnees/generate_data.py            # -> 04_Donnees/generated/

# 3. train + export models
python 02_Code_Source/ia/train_edge_detector.py    # -> results/edge_model.h ...
python 02_Code_Source/ia/train_fog_localizer.py    # -> ia/models/*.joblib

# 4. mandatory consistency check (PC sklearn vs C model.h)
python 02_Code_Source/ia/consistency_check.py

# 5. experiments
python 02_Code_Source/ia/experiments_live.py       # X5 latency, X7 robustness
python 02_Code_Source/ia/experiments_static.py     # X1-X4, X6, X8-X11

# 6. dashboard (demo mode works offline)
streamlit run 02_Code_Source/fog/dashboard/app.py
```

## Run the full stack (Docker: broker + fog + cloud + dashboard)

```bash
cd 02_Code_Source
cp .env.example .env       # edit values (TEAM_ID, passwords)
./fog/setup_auth.sh        # generates mosquitto/passwd + acl from .env
docker compose up -d --build
```

Services: Mosquitto :1883 (auth+ACL), Fog :8081 health, Cloud API :8000,
dashboard :8501.

## MQTT topic tree (TEAM_ID from `.env`)

```
m2i2a/equipeXX/edge/node{ID}/telemetry   QoS0  window features (loss tolerable)
m2i2a/equipeXX/edge/node{ID}/alert       QoS1  detection event (must not be lost)
m2i2a/equipeXX/edge/node{ID}/status      QoS1 retained + LWT
m2i2a/equipeXX/fog/localization          QoS1  top-k candidates + probabilities
m2i2a/equipeXX/fog/status                QoS1 retained
m2i2a/equipeXX/edge/commande/modele      QoS1 retained  Edge parameter push
```

QoS justification: telemetry QoS0 (bandwidth, high rate, loss tolerable);
alerts/commands QoS1 (reliability); retained status/commands for late joiners.
Note: PubSubClient (ESP32) publishes QoS0 only - the QoS1 behaviour is proven
with `edge/emulated_node.py` (paho) and documented in the report.

## REST API (Cloud)

```
POST /api/mesures           ingest measurement/event from the Fog
GET  /api/modele/latest     latest fog model (joblib) + x-model-version header
GET  /api/modele/versions   versions + metrics
POST /api/retrain           idempotent retraining (logs to results/)
GET  /api/drift             PSI drift score + retraining recommendation
GET  /api/health            liveness
```

## Security (E5)

- Mosquitto: `allow_anonymous false`, `password_file` + `acl_file`
  (see `fog/mosquitto/config/`). Users: `edge_XX` (write own telemetry/alerts,
  read fog + commands), `fog_XX` (readwrite team prefix), `admin_XX` (read).
- No secrets in the repo: passwords come from `.env` (git-ignored);
  `.env.example` ships with placeholders.
- Public-broker demo (Wokwi): topics are prefixed `m2i2a/equipeXX/`, no personal
  data, no passwords in the shared Wokwi project.

## Edge firmware notes

- `edge/edge_node.ino`: 3 FreeRTOS tasks (acq/infer/com), hardware-timer ISR
  releasing a binary semaphore, queues, JSON telemetry, LWT, offline ring
  buffer, retained command handling.
- `#define REPLAY_TEST`: replays `test_data.h` and prints
  `Accuracy on the Edge: x.xxx (N=500)` (X1).
- `model.h` is generated by `ia/train_edge_detector.py` (micromlgen export +
  `confidence()` patch - see the script comments).
- Consistency: `ia/consistency_check.py` compiles the same `model.h` with g++
  and verifies identical outputs on every replay vector.

## Model life cycle

1. `ia/generate_data.py` -> dataset; 2. `ia/train_edge_detector.py` (edge,
   exported to C) + `ia/train_fog_localizer.py` (fog, joblib, k-sweep);
3. `cloud/train.py` retrains + registers `fog_model_rf_vN.joblib`;
4. Fog polls `GET /api/modele/latest` and hot-reloads; 5. Fog publishes Edge
   parameters on `.../edge/commande/modele` (retained); 6. drift detection
   (`ia/drift.py`, PSI) recommends retraining (`GET /api/drift`).
